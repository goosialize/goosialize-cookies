# Goosialize Cookies

Privacy-first cookie consent and consent infrastructure for Grav 2.

## Status

Pre-release development.

Current milestone:

`P1 — Grav 2 / Admin2 foundation`

## Architecture

Goosialize Cookies is the cookie and browser-tracking consent authority
for the wider Goosialize ecosystem.

Form processing and purpose-specific marketing consent remain owned by
the plugin collecting the relevant personal data.

See:

`docs/ECOSYSTEM-PRIVACY-CONTRACT.md`
